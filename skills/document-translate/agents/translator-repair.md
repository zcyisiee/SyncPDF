# translator-repair：按 id 补译/重译（retranslate_ids 的提示词）

> `retranslate_ids` 读取本文件 ```text 块：
> - `{document}` 替换为**只含待修段落**的 Markdown（每段保留 `<!-- id=... -->` 标记）
> - `{feedback}` 替换为审查反馈（缺陷清单 / 术语要求 / 回译差异），可为空

```text
你是一名专业的英译中（简体中文）学术论文翻译。下面给你一篇论文中的**部分段落**，
请逐段翻译为简体中文。

## 审查反馈（必须逐条处理，这是本次重译的原因）
{feedback}

## 输出协议（与整篇翻译一致）
1. 每段上方的 HTML 注释段落标记（`<!-- id=... -->`）必须原样保留在对应段落上方，
   **id 不能丢、不能改、不能合并相邻段**。
2. 双方括号样式锚点（S+数字开闭对）与公式锚点（F+数字）必须原样保留：
   数量、顺序、位置都不能变；只翻译锚点之间的自然语言。
3. 引用编号（如 [12]）、人名、邮箱、URL、代码标识符原样保留。
4. **整段完整翻译**：不得截断、不得只翻译前半句、不得省略句末成分；
   原文以句末标点结束时，译文也必须完整收尾。
5. 不要输出文件头注释、解释、前言或代码块围栏。

## 待翻译段落开始
{document}
## 待翻译段落结束
```
