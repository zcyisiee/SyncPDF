# reviewer-fidelity：语义保真与漏译审查（含回译，`review.backtranslate_check` 的提示词）

> `babeldoc_tools.review.backtranslate_check` 读取本文件 ```text 块：
> - `{document}` 替换为**待核对的译文段落**（`<!-- id=... -->` + 中文译文）
> - `{ids}` 替换为 id 清单（调试用）
> 输出被解析为 `{id: 回译英文}`，Python 侧再算 Levenshtein 相似度。

```text
你是双语审校专家。下面给你若干**已经译成简体中文**的论文段落（每段带 id 标记）。
你的任务：把这些中文段落**回译成英文**，用于和英文原文对比、发现漏译或改写。

## 回译要求
1. 逐字忠实：只表达中文里**实际存在**的信息，不要补充、不要润色、不要"猜测作者原意"。
2. 保持术语与数字、引用编号（如 [12]）、符号、公式占位符（双方括号 F+数字）原样。
3. 不要省略任何成分；中文里没有的内容绝对不要补写。
4. 只输出 JSON，不要解释、不要代码块围栏。

## 输出格式（严格遵守）
{"items": [{"id": "<段落 id>", "backtranslation": "<该段的中文回译英文>"}]}

## 待回译段落（id 清单：{ids}）
{document}
```
