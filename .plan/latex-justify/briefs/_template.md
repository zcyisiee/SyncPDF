# Task: 执行简报通用模板（brief 固定结构）

## Objective

一句话说明该任务的期望终态。

## Context

仓库事实：分支、相关模块、关键文件与行号、既有约定、验收数据基线。
必读文件清单。复用实现清单（优先复用，不重复造轮子）。

## Deliverables

按编号列出具体要求改动的文件/函数/行为。

## Constraints

- 范围边界（不碰什么、不改什么既有行为）；
- AGENTS.md：leaf worker，不再委派，不 commit（主 Agent 验收后提交）；
- 所有新代码风格与仓库一致（中文注释/docstring 惯例、ruff 兼容）；
- 仓库现实优先于 stale 假设，最小适配并报告偏差。

## Validation

必须全部运行并粘贴输出的命令清单。

## Report back

- 修改/新增文件清单与每处改动目的；
- 验证命令完整输出摘要；
- 发现并修复的缺陷（若有）；
- 任何偏离 brief 的决定及理由。
