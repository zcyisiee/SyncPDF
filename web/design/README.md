# 工作台设计稿（静态原型）

`index.html` 是面向普通用户的 ieeTranslater 工作台**设计稿**，不是应用的一部分：

- 纯静态单文件 HTML（内联 CSS/JS + 示例数据），不参与 `vite build`、`tsc`、vitest 与 e2e；
- 用来先定版式与交互逻辑，确认后再接进 `web/src`（React）实现；
- 三栏骨架：左栏 论文卡片（一篇论文 = 一个工作区）→ 中栏 预览工具条（含任务切换器）+ 纸面 → 右栏 inspector（段落 / 事件流 / 归档 + 底部操作区）；没有顶部状态栏，也没有独立的任务标签栏。
- 段落**不给列表**：用户直接在纸面上点段落，右栏主体就换成该段的「原文 · EN / 译文 · ZH」，改字即时生效（失焦写回草稿）；右栏不设筛选与段级按钮。
- 事件流是两条**并列**的流水（翻译与检查 / 编译与预览），共用一套节点语法：类型图标圆标 + 类型文字 + 每条独立序号；时间与耗时收进「展开详情」；列宽不够（右栏拖到 ≤320px）时自动退回单列。

## 接入 `web/src` 时的验收要点

定稿原型里这几条是所有状态都成立的：

- 1440 / 1180 / 980 / 820 四档视口：`app` 行高 = 视口高、无页面滚动、无横向溢出；滚动只发生在画布与右栏内部。
- 右栏栅格 `44px minmax(0,1fr) auto`：未点选段落时第三行塌成 0（实测 `44px 856px 0px`），点选后 `44px 738px 118px`。
- 中栏只有「工具条 + 纸面」两行（`40px minmax(0,1fr)`），1440×900 下纸面 860px 高。
- 事件流两列等宽（右栏 340 → 156 + 156；右栏 520 → 246 + 246），窄列内文字只折行、不截断。
- 颜色、间距与字体令牌以 `web/src/app/globals.css` 与 `web/tailwind.config.ts` 为准；原型里有一份 oklch 变量的近似实现，接入时要对齐。
- 本轮复核用的脚本与截图在本仓库 `tmp/design-review/`（已忽略，不入库）：`shoot.mjs` 各状态几何断言、`tl.mjs` / `tl2.mjs` 两列与容器查询、`abgate.mjs` 操作区出现时机。

本地查看：

```bash
cd web/design && python3 -m http.server 8899 --bind 127.0.0.1
# 打开 http://127.0.0.1:8899/index.html
```

`index.html#state=<state>` 可直接进到某个关键状态，用于评审：
`default`（默认工作台）、`events`（事件流）、`archive`（归档版本）、`compile`（编译模式抽屉）、
`draft`（术语待确认）、`retry`（翻译失败）、`running`（翻译进行中）、`empty`（未创建任务）。

原型状态会写进 `localStorage['ieet.v1']`；带 `#state=` 打开时以 hash 指定的状态为准。想回到初始态，在控制台执行 `localStorage.removeItem('ieet.v1')` 后刷新即可。
