## 2. 任务拆分

约定：
- 一个任务 = 一个 crate 或一个前端目录内的改动，≤ 800 行新增代码（含测试）。
- 「组」内任务无相互依赖，可并行派发。组按序号推进。
- 每个任务的 brief 必须列出：允许修改的路径、禁止的 crate、验证命令。
- 所有任务的测试不得访问网络。LLM 用假翻译器；模型文件用 `SYNCPDF_MODELS` 环境变量指向本地目录，缺失时测试 skip 并打印原因。

## 7. 假翻译器

| 名称 | 行为 | 用途 |
|---|---|---|
| `echo` | 原文返回 | 回写正确性、膨胀比、链接 |
| `stretch:1.4` | 每个词重复到长度 ×1.4（CJK 逐字重复） | 溢出 / fit 阶梯 / 加宽 |
| `shrink:0.6` | 删词到 ×0.6 | 对齐 / 短行 |
| `cjk` | 把拉丁词替换为等长伪中文（从固定字表取） | CJK 断行、字体子集 |
| `fail-every:n` | 每 n 段返回违规 HTML | 校验器 / 拆分重试 / fallback 事件 |
| `slow:ms` | 延迟返回 | 取消 / 并发 / 进度事件 |

全部实现为 `Translator` trait 的实现，CLI 用 `--translator` 选择。

## 8. 性能门禁（release 模式，Apple Silicon 基准机）

| 指标 | 门禁 | 测法 |
|---|---|---|
| 单段排版 | <1ms p50 | `bench typeset` |
| 12 页全量回写（echo） | <2s | `bench writeback fixtures/up-vns.pdf` |
| 30 页端到端（不含 LLM，含布局模型）| <15s | `bench run --translator echo --pages 1-30 fixtures/up-2602.pdf` |
| 单段编辑 → paragraph 事件 | <100ms | pipeline 单元测试计时 |
