# 初版验收修复 · 用户确认契约

用户已通过 questionnaire 明确批准以下范围，2026-09-18 开始实施。参考问题：acceptance-round1.md。

## 产品决定

1. 六项全部修复：窄栏、翻译配置、类别筛选、连续阅读、缩放、类别描边。
2. 保留浅色三栏。工具栏可分行，低频功能收进更多；不自动隐藏侧栏。
3. 所有 PDF 预览连续纵向阅读。提供缩放按钮/比例/适宽，触控板捏合仅缩放 PDF。保留普通滚动和放大后的平移。
4. 对照默认按页码及页内相对位置联动，允许解除；不承诺逐段对齐。
5. 识别默认原文＋识别框，翻译默认译文＋版面框；每视图会话内记忆选择，缺源文件时明确提示并可切换。
6. bbox 类别色稳定、默认可见细描边＋浅填充（明确允许类别语义色，不受旧版单强调色限制）。实际标签驱动，不硬编码仅 19 类。逐类显隐、全选/全不选；全局描边粗细及填充透明度设置。类别筛选按文档持久化，样式全局持久化。计数明确当前页。隐藏框不能拦截点击；不改变识别产物或翻译范围。
7. 模型配置为主、脚本为高级选项。本轮支持 OpenAI 兼容 Chat Completions 接口，自定义 Base URL、模型、API Key。不是只做表单，必须能进入真实 bdt 翻译执行链。
8. 凭据本机后端持久保存，文件限当前用户读取，禁止回传明文、写入日志或 Git；这是文件权限保护，不宣称加密。保存不自动调用模型。手动“测试连接”发送短生成请求，说明可能费用；有清楚且脱敏的认证/地址/模型/超时错误。
9. 翻译配置必选；AI 审校可选默认关，能选择同一/不同模型配置；本地排版/链接检查保留。现有脚本兼容性与白名单不退化。
10. 所有外部命令功能归 bdt 子命令/参数，不增加并行 CLI 入口；以现有仓库实际包布局为准，不新造第二个包。

## 实施及验收边界

- 不重做翻译质量算法或全站主题，不升级无关依赖，不提交/推送 Git。
- 不调用真实模型、不读取现有凭据来发请求；离线 stub 服务可测试协议。真实调用在界面配置后另行请用户批准。
- 不用现有用户文档做写入实验，不篡改 tmp 现有 profile/草稿/产物。
- 测试结果留仓库 tmp/；pytest 用 .venv/bin/python，PATH 加 .venv/bin，唯一 --basetemp 带时间戳；改动 Python 跑 ruff，前端 typecheck/lint/test，最后 diff --check。
- 单写者串行分模块实施；主控亲自审查 diff 和重跑验证。测试通过不能替代浏览器视觉/行为验收。
- 物理 Mac 触控板及 Safari 手感最终需人工验证，不能把模拟 wheel 等价表述为真设备通过。
