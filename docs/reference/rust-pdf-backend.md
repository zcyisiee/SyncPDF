# Rust PDF 后端当前边界

`engine/` 是正在开发的 Rust 后端；`syncpdf-cli` 用作内部 sidecar 与开发验收。产品入口约束仍是 `bdt`。这里描述代码现有行为，不表示已完成全篇翻译质量验收；专项进度见 [Rust 后端 task state](../reports/2026-09-22-rust-electron-rewrite/task-state.md)。

## 事件通道

Unix `run`/`translate`在原生组件加载前用安全FD API保留原stdout为JSONL专用writer，并将fd1重定向至stderr；重定向不恢复，覆盖运行结束后的原生库日志。副本原子设置close-on-exec，避免翻译子进程继承事件管道、拖延EOF；隔离失败传播错误。事件仍逐行flush、保持seq/时间戳，Python继续严格拒绝任何无效事件。非Unix不改FD；inspect/help/version行为不变，此隔离不修复CoreML自身缓存/模型警告。

## 解析与绑定

PDFium 提供对象/字符几何，lopdf 提供源操作与字节。调用方必须保证两者读取同一不可变输入版本；先全页绑定，再修改 lopdf 文档。`BoundPage::check_replacement` 在 source 返回翻译输入前和公共删除 API 中检查已知异常、重复源操作、页身份与完整源跨度。

真实源 code 与提取字符不一一对应：generated 空格不具有可删除字节；连字可包含多个 Unicode 字符；折叠空格保留源 code；明确空映射无法得到可信几何时拒绝替换。CMap 支持 bfchar/bfrange 与 UTF-16 代理对。通过门禁不代表未知编码、所有 fallback 或全部 PDF 已获认证。

PDFium 去重后缺少字符的对象，仅在严格匹配的单 code `Tj`、自身有效 rotated bounds/matrix、有明确 ToUnicode/Encoding 证据时恢复。对象几何与字符几何分开记证据和统计；Type0 恢复仅支持完整 Identity-H 双字节 code。多 code、TJ、Identity-V、未知/冲突映射继续拒绝。

## 删除与写回

`PatchSet::delete_glyphs(&BoundPage, ids)` 先检查整批请求再入队。pipeline 将同页已准备的段落汇成一批，使用 1 基页号。apply 在私有文档候选上克隆目标页 Contents 和资源容器，唯一顶层 Form 克隆并按精确 Do 操作改名；全部成功后才替换原文档。共享流的其他页面不应随目标页删除而改变。

成功 apply 后旧绑定失效；若要再次编辑同页，需保存并由新版本重新绑定。重复 Form 实例在 source 拒绝；嵌套/重复目标 Form 不支持写回。绑定时私有保存页 Contents 有序引用和遍历到的源流解码字节；同页不同快照不能混排。apply 在候选修改前整批比对，拒绝同 ID 流的原地修改以及 Contents 的添加、移除和重排。这项门禁不认证字体/资源对象的语义变更，也不替代两套解析器使用同一原件的调用约束。

## 译文字形与字体嵌入

布局后处理仅凭可核实的物理行或源框线修正分区：同栏正文末行的漏出续文归入独立 Text 行；算法标题、三条源横线及贯通栏缝共同支持时，拆开 Code 与右侧说明。证据不足时保持原分区并报告 coverage gap，不以扩大不可译区域消除统计缺口。单行 `(a)` 等子标题须有标签、紧邻图表且居中的几何证据才补入 Caption；居中子标题使用所属面板宽度，同物理行的保护文字仍阻挡。重叠可译区域按较小面积及稳定序号唯一分配字形，避免同一源字形删除两次。与 Code、Table 等保留区域共享字形仍阻断，并发 `protected_source_overlap`；嵌套 Formula 只在下述源原子证明成立时例外。

行内公式须全部归属一个正文区，且不与其它保护区、图片、无关字形或跨界路径相交。沿邻近正文基线归一化上下标分行后，以 `Atom.source` 保存源 bbox/基线，作为 KEEP 送译。排版按原尺寸/基线放置，`LineBox.placed_atoms` 记录源与目标几何；较高公式只增加发生墨迹碰撞处的局部行距，不缩公式或正文。写回从不可变源页隔离公式文字/路径，复用原字体和内容流，通过 Form 重放到目标位置；私有副本清除其它文字（包括嵌套图片 Form），原图不修改。成功页原位置的公式字形随段落删除，局部裁剪移除原公式路径。所有操作仍在页候选事务内，失败不得发布半成品。缺少可靠几何/字节绑定的公式继续明确回退。

尾逗号只在有有限正tight ink、处于正文基线且前一数学字形字体不同、式内及正文前缀定界符严格配对、后继可证明为两个完整同字体正文词且没有保护冲突时从Formula中释放。同排或相邻续行均需具体几何证据，未知字形不能跳过；单字母不是正文证据。减小后的原子重新执行完整clip门禁，若仍碰逗号墨迹则撤销释放。源区域重叠豁免仅属于最终实际附着同一source atom的段及精确GlyphId，不把页级候选权限借给其它段。此能力不包括外层括号或尾冒号。

漏检行内根式仅在单个√、唯一直接实线overbar、完整同基线被开方字及唯一正文归属都有证据时恢复源原子；要求tight ink、已知细笔画和无竞争绘制。字形分行使用被开方行盒，避免过高loose根号盒桥接相邻行。无证据、多条竞争横线或复杂嵌套形状不猜测。

可见非空白控制码字形不作为普通Unicode重新排字：独占归属、tight ink、源span及行基线可靠且无邻字/路径/图片冲突时，保留为源绘制`Symbol` KEEP，不猜替代字符。无法证明时发`unmapped_source_glyph`、保留源段并计入未完成；已有源绘制原子不重复认领。下游`text_atoms::resolve_text`同时接受具有源绘制及精确源span的`Formula`/`Symbol`，保留KEEP直至原尺寸重放，不扩展到无source的Symbol或任意Other；非法范围、缺样式或文本不符仍拒绝。回归覆盖保护→解析→prepare接缝及真实缓存复排。此保护不是通用字体编码修复。

`Glyph.ink`保存PDFium tight bounds，不替代用于布局/归属的loose bbox；簇中任一字符缺墨迹证据时整个簇为None。旧IR缺字段可读取但仍保守使用loose盒，生产重新绑定页面提取新证据。公式擦除/重放clip与碰撞检查使用同一墨迹及已归属路径范围，不能用tight通过碰撞后再按更大的loose盒擦除。安全侧承平移可连同SourceAtom目标框刚性移动，源框和原尺寸保持。

Writer 为每个字体按原 GID 首次出现顺序分配 CID，内容流使用 CID。finalize 在同一次子集化后把 CID→原 GID 转成显式 CID→子集 GID；Encoding、宽度表与 ToUnicode 均以内容 CID 索引。字号只写入 `Tf`，`Tm` 保留无量纲横向缩放，避免字号平方。字体 Type0 字典搬入预留资源槽后，删除其临时尾对象时同步回收该最高对象号，保证表式 xref 的 Size 一致。

ActualText/ToUnicode 的文本检查不能证明实际字形正确；内置 Noto CJK CFF 与 PT Sans TTF 已用原字体独立渲染对照。此项不认证任意字体或完整排版质量。

字体包按资源名排序分配字体编号；段落基线与容纳计算使用段内实际字体的度量，不读取无关的固定编号字体。默认排版保持请求字号与行距，容纳失败返回 `Overflow`，不自动缩小字号。显式配置旧阶梯的库调用仍保留兼容性；生产 pipeline 固定为源字号或用户请求的字号，不作失败后的自动缩小。溢出段不进入删除/译文写入集合，保留原文并发带页号和段落ID的 `typeset_overflow` 提示。源StyleRun保留精确字号和颜色，排版/Writer逐run传递；源行距以pt保存，在typeset适配处转为字号倍数。`bdt rust-translate --font-scale 0.9 --line-height 1.3`通过本地RunConfig/Typography仅修改目标ParagraphSpec：所有StyleRun字号同比缩放，行距用缩放后段落主字号×倍数推导，不维护独立目标pt设置。省略参数维持原行为；只传font-scale时保留源行距比例。初始化沿用首行源基线；页提交前动态bbox可在同栏净空内受控移动基线。颜色、字体角色及标题/小字大小层级保持，源IR与翻译缓存身份不变；不可译及回退原文不缩放。结果JSON保存本次倍数。此配置目前由CLI接入，未扩展编辑协议。目标`Text`区域使用衬线族，zh-CN为Noto Serif CJK SC（思源宋体）；原bold/italic/字号/颜色保持，mono仍优先原等宽选择。无样式译文StyleId(0)也使用该正文策略。其它区域（含Title/ParagraphTitle/Abstract/Caption/List）保留原字体选择，源serif/mono标志仍参与；不修改全局Body链、源IR或缓存，编辑覆盖仍需后续接线。真实fallback身份、cluster安全和实际墨迹容纳已接，并由R3工程验收验证。行间碰撞用整行框作初筛，再核对逐字形墨迹框（未知轮廓用保守字体度量）及原子矩形；不同横向位置的上伸/下伸部不再仅因整行框相交而误报，普通字形真正相交仍拒绝；原尺寸源公式导致的相交仅增加必要行距，字号及碰撞容差不变。完整论文质量仍需逐项评估。

标题的源bbox用于定位和源字形归属，不强制限定目标行宽或原文行数。同一Title/ParagraphTitle区域内，字号差不超过10%、行距小于1.8倍字号且中心轴相差小于2pt的行，不按左缘缩进误拆段；编号标题的续行与编号后正文起点相差小于2pt且不含新的编号时，同样合段；居中段首行缩进为0。不同区域、大行距或不同字号仍分开，普通正文保留原缩进规则。标题合段改变翻译单元身份，须按新源文本真实翻译，不能拼接或改名旧缓存。

标题初始LayoutFrame以源框和布局区为基础；页面居中的Title可使用下方Text/Abstract区域整体横向范围，其他标题只使用下方最近、左缘差不超过4pt且覆盖源宽的正文区域。同排保留字形/图片继续收窄横向空间，垂直空间和实际墨迹仍执行原碰撞检查，中心轴与初始基线不变。目录行在明确、唯一的本地Link完整覆盖标题且右侧仅点线/页码时，拆成可译标签和受保护尾部；所有源行均能证明才拆分。标签区域可使用至尾部前的无字形空白（不改段落源glyph bbox），单行标题的相邻保护页码栏提供横向容器，避免被其它行的缩进误收窄。无正文或目录容器证据时保持原规则。该策略不改源IR、作者保护或表格边界，也不额外调用布局模型；长译文或大字号仍可正常换行，不能容纳仍明确回退。

断行代价必须与实际对齐一致：左/中/右对齐按自然宽度及行尾余量评分（含末行，避免留下孤词短尾），两端对齐按可拉伸间距评分。无可拉伸间距的片段只在后续合法断点确实放不下时允许短行兜底，避免英文数据集名被低代价单独甩到短行。自动断行不把单个CJK字及末尾标点留作末行，显式硬换行保留；不修改模型译文或依赖人工插入换行。

数学字符由内嵌STIX Two Math（OFL，许可证随字体保存）回退，不依赖系统字体或TeX，不将数学斜体Unicode换成普通字母。左右侧承造成的越界，仅在整行实际墨迹可完全容纳时利用另一侧余量平移纠正，不裁字、不缩字、不扩大容差。源路径`n`会清空未绘制路径，Form子绘图受其入口CTM下的BBox限制；这些是障碍几何修正，不修改源图。

页内全部译块落定、保存前，只重试尚未排入的合法译文，最多3轮，无改善即停。净空来自不可变源页减去实际替换字形，加上已接受译文的真实墨迹；保留文字/图片/框线仍阻挡。候选依次为同栏垂直bbox回收/基线移动、保持左锚点向右利用实际空隙、与同栏连续下方已译段联排。横向上限为原页可见文字右边界和同高度实际障碍，不能扩到纸张边缘；加宽后重新计算纵向净空。联排按源顺序逐段纳入同栏锚点、足够横向重叠的连续下方已译段，找到可容纳组即停；受本页段落数约束。保留顺序和源段间距，组内每个源框须与同一净空带相交，不能跨越固定障碍；全组容纳与链接几何同时通过才更新位置，失败不移动原成功段。固定字号/行距，原页保存事务不变。不做跨页搬移、跨固定障碍/整页重流、表格单元格扩展或译后模型重检测。发`layout_refined`证据；`PageReady`前初始fallback可被后续typeset取代，消费者应按段ID取最新状态，不能把出现过的fallback永久累计。页保存后不再重排，原子保存/revision边界不变。

源文本下划线使用`DisplayItem::Path.stroke`的页级OpKey/线宽/颜色证据，`Paragraph.decorations`记录独占归属，`StyleRun.underline`随范围拆分。仅直接m/l/S(s)、无活动裁剪、已知实线画笔及同尺度CTM可绑定；线宽转换到页坐标。`W/W*`作用域持续到Q，不因n或paint清空。虚线、未知ExtGState、非默认线帽等不认领；公式原子已包含的路径也不认领。

初始frame仅忽略自己的已证明装饰，源IR不移除路径；refine只让有锚点的候选/已落定owner让出原线，并加入目标下划线障碍。空格短线需两端同owner、同画笔且连续相接。每个下划线源范围都要求非空译文样式锚点，内部link别名继承范围；缺失时报`source_decoration_unanchored`并保留原段。此要求不扩到普通样式。成功段与链接几何通过后，页候选`PatchSet::delete_paths`将准确的S/s改成无操作数n，保留构路及graphics state；writer按目标墨迹/基线和原线宽/颜色重绘，下划线计入真实边界与碰撞。源绘图原子的额外下划线尚未支持，不能静默删去。

## 源文本与 Markdown 传输

`Paragraph.text_spans` 将阅读序文本映射到真实源字形范围；由几何证据生成的词间/行间空格使用零长度范围，不产生可删除的假字形。段落文本、原子识别与翻译单元使用同一映射；保留显式空格、连字和行末连字符。缺少几何分隔证据时不能保证所有词边界都能恢复。旋转侧注暂时保留源绘制并提示。重叠可译区域先分配唯一字形所有权，无法证明安全的保护冲突仍保留并提示。`FootNote` 与代码、reference 等类别不参与翻译。首页有可靠标题/摘要边界时，结合邮箱、机构和相邻姓名/地址布局保护作者信息；不支持的布局不泛化猜测。明确Author List/Authors/Contributors标题之后，严格姓名格式的逗号分隔名录保持保护，可跨页延续；叙述性贡献文字仍可译，遇下一个标题结束范围。Figure边界漏掉的邻接图内文字仅在同一独占Form实例、窄邻接带且无新冲突时归回Figure；仅同资源名或同全页Form不构成独占证据，未知仍报覆盖缺口。

模型输入输出使用 `syncpdf-markdown-v1`：独占行 `<!-- syncpdf:block P01-001 -->` / `<!-- syncpdf:end P01-001 -->`，样式 `[文字]{style=1}`、原子 `{{KEEP_1}}` 和反斜杠行末硬换行。完整闭合块立即校验并交付排版，不等模型 EOF；正确闭合且ID可识别的正文语法错误记为 `invalid_markup`，坏块不交付、不缓存，其余有效块继续立即交付；坏块进入现有最多3轮的补译，耗尽后明确回退。成功通道中的边界损坏或EOF半块会丢弃损坏点及其后全部内容，若该请求尚有未落定的源ID，则标记`invalid_markup`并复用上述有界补译；先前的数字等违规原因保留，不猜ID或接纳看似有效的后缀。没有可重试源ID的坏尾仍报错。真实通道失败原样上抛且不补译，此前已严格交付/缓存的完整块保留。HTML 仅保留为内部单元/校验/事件兼容格式。

默认一个主请求，不按页自动切片；显式 `PromptSpec.max_chars` 限制 system+text 字符数，超限不发该请求。主请求和有界补救请求分别计数，通过 `translation_requests` 事件报告。缓存 hash 包含传输版本、当前学术翻译规则全文和非空规范化术语表，命中仍需结构校验。`bdt rust-translate --glossaries <csv>`复用共享CSV loader（去空白/后者覆盖/排序）；非空note报`glossary_note_unsupported`，缺失/坏表在创建运行产物前失败。Python将二元映射写入`<workdir>/tmp/terminology.json`，内部CLI `--terminology`/Run.terminology消费该JSON，主/补救请求共用PromptSpec词表。Rust拒绝空字段、坏形状及同源冲突；缓存按排序去重的映射隔离，manual优先级在各词表键内不变。空表不增加键材料（同规则下兼容旧无表缓存）；整个词表变化会使该表下的旧译文不命中，cache-only不会因此调用模型。规则更新后旧缓存条目保留但不命中，不能把旧规则译文当成新规则翻译。已按用户要求删除目标语字符比例、样式片段数量及空样式门槛；模型可按译文语序换序、拆合、复用或省略已知样式，英文术语较多不再导致拒绝。仍校验块/KEEP/数字等内容身份、已知样式引用及传输结构。数字违规补救额外附逐块只读源数字多重集（含重复次数），与校验共用数字提取函数和跨style文本规则，不包含block/style/KEEP编号或ATOM_HINTS数字；只列本轮数字违规块，不改变主请求、缓存身份和重试上限。提示要求量纲词仅翻译单位、不换算尾数，拼写月份/数量用目标语文字；加入清单后仍检查完整请求容量，不放宽数字守卫。提示词保持该样式自由度；学术要求由根目录`TRANSLATE.md`适配到`syncpdf-translate/src/academic_rules.md`并编入请求，强调忠实简洁、全篇术语一致、首次技术术语括注、短段不可遗漏、圈号序号保留和中文罗马章节编号。原Python的样式/公式/id-label语法改用Rust style/KEEP/block-end，标题/图表说明样式仍由元数据表达，不添加不受支持的Markdown语法。规则修改需重新构建Rust引擎；旧运行未保存的拒绝回包不会自动成为有效缓存。被拒回包正文尚未持久保存，历史错误码不能当作实际译文逐字对照。未知/重复输出块不进入排版并阻止完整成功状态。真实模型的容量、输出协议遵守和全篇质量仍需实际验收。

## 尚未闭合的后端能力

pipeline 的页提交先克隆候选主文档，删除该页成功段落，并仅重放已提交页与当前页的译文；原子保存成功后才替换主文档、更新 revision 和发 PageReady。重复落定块幂等；未知块、缺绑定、删除/保存错误传播并停止后续处理。输出自检只对实际写入 CJK 的页要求 CJK；自检/链接对照错误阻止发布完成事件，最终发布沿用已验证的最后快照。

部分段落回退、源区域归属冲突或 coverage gap 时，保存可读的部分结果并发 `translation_incomplete`，RunFinished/RunSummary 的 ok=false，CLI 非零退出。reference/脚注等按策略保留的内容不算失败。薄封装结果单独报告 `blocked_before_translation` 和 `coverage_gap_pages`，送译前冲突计入未成功块，覆盖缺口阻止完整成功；不能只用下游 fallback 数评价覆盖。普通数字原子以准确原文回填，可跨相邻源样式；在目标样式片段内跟随模型选定的已知样式，无目标样式时继承第一个源字形样式。`Other` 中严格匹配 `[2]` / `[17, 8]` 的数字引用也可回填，但额外要求阅读序span完整、连续覆盖源glyph范围且文本精确一致；不更改Markdown传输版本或缓存键，KEEP身份仍须通过校验。HTTP(S) URL也要求完整精确源span后按原文恢复。链接准备统一覆盖有atom和无atom段：KEEP内引用使用源偏移和原子身份；旧缓存未标记引用要求唯一文本匹配，重复标签只能在目的地一致或中英文表/节等上下文足以消歧时接受。内部临时样式标记携带锚点到目标字形，按行生成Rect/QuadPoints，在页候选事务中更新原注释且保留Dest/A。模糊匹配、非Link注释或跨段注释所有权不清仍拒绝，不能简单删除注释门禁。源公式内的链接按公式实际位移移动原Rect/QuadPoints，不将公式文本当作普通文字查找；跨公式边界且无法唯一归属的链接仍拒绝。链接验收必须以最终保存PDF为准；这不是任意语言/任意注释格式的认证。无源绘制证明的公式及不支持的Other仍保护回退。

明确本地`cite.*`引用的连续源span可成为`Citation`文本KEEP，以区分重复人名/年份及跨行注释片段，不依据目标出现次序猜目的地。要求没有段外共享字形、源文字精确一致且不把不同源样式压成一个样式；其他/未知链接仍沿用原门禁。仅一个Link精确拥有整段全部可见非空白源字形、没有段外归属及竞争注释时，可按段落身份锚定完整译文（如翻译后的目录标题）；部分链接不能扩成整段。点击框取逐行实际字形墨迹：确知空白可跳过，无文本的簇后续字形仍须测量，不把空字符串视为无墨迹。

上述公式方案认证有可靠源几何的行内原子；任意公式布局、段落空格/阅读序和超出上述范围的链接仍需各自验收。`links_check()`本身仍只检查数量/目标解析；不能单独作为点击几何验收，须结合锚点与保存后PDF检查。生产 Rust 排版不调用 LaTeX；TeX/旧 bdt 可用于质量对照。

验证命令与证据保存在专项交接和 task state。所有测试缓存、截图、日志保留在仓库 `tmp/`；不使用用户文档库 `~/.sp` 作测试库。

## MVP 调用

`bdt rust-translate <pdf> --workdir <新目录>` 调用已有Rust sidecar和pi真实模型；可指定页范围、模型及CoreML。最终JSON与事件保存在workdir，部分结果继续返回非零退出码。它不执行旧Python排版流程，不调用LaTeX，也不新增UI。`--cached-from` 只读复制既有译文缓存，并令本地RunConfig.cache_only模式跳过主请求和补救请求；未命中/校验失败块明确回退，仍完成页级保存与最终自检。使用说明见[CLI指南](../guide/cli.md)。


## A3 双语导出

`bdt rust-translate --dual` 将可选目标路径传入内部 sidecar 的 `--dual-output` / `RunConfig.dual_output`；未扩展尚待实现的编辑/Export请求协议。单语译文校验后，publishing阶段调用`syncpdf-pdf::dual::export`并执行保存后自检，成功发`dual_exported`事件，再发最终完成事件。默认不导出；请求失败仍保留单语文件并报告失败。两输入PDF不修改，输出经同目录临时文件原子保存。

每张A3横向纸固定420×297mm，一一配对原文/译文的同页。源MediaBox/CropBox、继承资源和0/90/180/270度旋转共同确定可见页面；左右各在半页内等比居中。页面内容流及字体/图片资源封装为独立Form，不截图栅格化，也不重新翻译或修改段落字号配置。整页适配A3的比例与段落font-scale是两层不同变换。

导入译文对象前重编号，避免跨PDF对象和资源冲突；复制页面透明度Group。Link Rect/QuadPoints及本地目的地随所属页面矩阵转换。右侧命名链接先解析为显式目的地，避免与左侧同名目标冲突；URI保持。沿用左侧原文目录和命名目标，不复制第二套目录。Fit/FitB改为对应半页FitR，FitH/FitV系列改为变换后的XYZ锚点。页数不一致、无效页面尺寸/旋转及无法解析的已用命名目标明确报错，不输出假成功。已验证普通论文文字/图形和链接；任意表单、交互批注外观、标签阅读树等尚未认证。

两端对齐按advance扩字距后，如果衬线墨迹宽度略超可用宽度、自然字距的完整墨迹却能容纳，则仅减少新增glue拉伸（不低于自然字距）再放置；保持断点、字号、行距和字形宽度，实际墨迹仍通过原容纳/碰撞门禁。真实Text字体切换及验收见[宋体验收](../reports/2026-09-22-rust-electron-rewrite/12-MVP真实翻译验收.md#text-serif-font)。
